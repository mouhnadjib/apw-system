# خادم المجلس الشعبي الولائي (المرحلة 1)

FastAPI + PostgreSQL، يعمل على حاسوب المجلس عبر Docker، ويُنشر على الإنترنت بـ Cloudflare Tunnel دون فتح أي منفذ.

## التشفير
| الطبقة | الآلية |
|---|---|
| النقل | HTTPS (يوفّره النفق) + HSTS |
| القرص | LUKS على الحاسوب (يُفعَّل عند تثبيت Ubuntu) |
| الحقول الحساسة في القاعدة (نصوص الأسئلة والإشعارات) | AES-256-GCM بمفتاح `APW_FIELD_KEY` |
| الملفات (صور النواب، الردود الممسوحة) | AES-256-GCM بمفتاح `APW_FILE_KEY` |
| كلمات مرور الموظفين | Argon2id |
| رموز الدعوة والتحديث | بصمة HMAC فقط، لا تُخزَّن صريحة |
| إشعارات FCM | نص عام فقط، لا محتوى حساس |
| النسخ الاحتياطية | GPG AES-256 (`backup.sh`) |

**احتفظ بنسخة من `.env` خارج الحاسوب**: ضياع `APW_FILE_KEY` أو `APW_FIELD_KEY` يعني ضياع البيانات المشفّرة نهائياً.

## التشغيل على الخادم
1. ثبّت Ubuntu Server 24.04 مع LUKS، ثم Docker.
2. `mkdir -p /srv/apw/pg /srv/apw/data secrets` ثم ضع ملف حساب خدمة FCM في `secrets/fcm.json`.
3. `cp .env.example .env` ثم ولّد المفاتيح: `docker compose run --rm api python -m app.cli gen-keys` وانسخها إلى `.env`.
4. في لوحة Cloudflare أنشئ نفقاً وجهته `http://api:8000` وضع رمزه في `CF_TUNNEL_TOKEN`.
5. `docker compose up -d --build`
6. أنشئ الأدمن: `docker compose exec api python -m app.cli create-admin admin "الاسم الكامل"`
7. جدولة النسخ الاحتياطي: `0 2 * * * /path/backup.sh /mnt/backup`

## الاختبار محلياً
`pip install -r requirements.txt && python -m pytest -q`

## واجهات البرمجة
- `/auth`: دخول الموظفين، تفعيل النائب برمز الدعوة (يربط الجهاز)، تحديث الجلسة، خروج
- `/admin` (أدمن): الموظفون، الدورة (5 سنوات)، اللجان، النواب، الصور، رموز الدعوة، إعادة ضبط الجهاز، سجل العمليات
- `/staff` (أدمن + مستخدم التسيير): الإشعارات (للجميع/لجان/نواب)، مسار الأسئلة، رفع الرد الممسوح
- `/me` (النائب): الإشعارات (لا يرى النائب غيره من النواب)، الأسئلة (إنشاء، تعديل بعد الإرجاع، متابعة الحالة، تنزيل الرد)

مسار السؤال: `submitted → under_review → (returned → submitted) → confirmed → referred → answered`
التعديل يقوم به النائب نفسه بعد إرجاع الديوان للسؤال.

## لوحة الأدمن
تُخدَّم من الخادم نفسه على `/panel/` (مثلاً `http://localhost:8000/panel/` أو `https://<نطاق النفق>/panel/`) وهي مبنيّة مسبقاً، فلا يلزم Node على الخادم.
للتعديل على الواجهة: `cd panel && npm install && npm run build` (يُخرج البناء إلى `app/static/panel`).
اختبار المتصفح الشامل: `python tests/e2e/e2e_panel.py` (يتطلب playwright).
ترتيب الإعداد الأول: إنشاء الأدمن ← دخول اللوحة ← الدورة واللجان ← الموظفون ← النواب (صورة + رمز دعوة).
