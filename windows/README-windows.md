# التشغيل على Windows 11 (بلا Docker)

## 1) التحضير (مرة واحدة)
1. **التشفير:**
   - *Windows 11 Pro:* افتح PowerShell كمسؤول ثم `manage-bde -on C: -RecoveryPassword` واحفظ مفتاح الاسترداد **خارج الجهاز** (مطبوع أو فلاشة).
   - *Windows 11 Home:* الإعدادات ← الخصوصية والأمان ← تشفير الجهاز (يتطلب TPM). إن لم يتوفر فاستعمل VeraCrypt لتشفير القرص.
   - يُفضَّل حامي TPM فقط (بلا PIN) كي يعيد الجهاز التشغيل ذاتياً بعد انقطاع الكهرباء. الثمن: حماية أقل عند سرقة الجهاز كاملاً، ويعوّضها حبسه في مكتب مقفل.
2. **البرامج:** Python 3.12 (فعّل خيار py launcher)، PostgreSQL 16 (سجّل كلمة مرور postgres)، 7-Zip، cloudflared.
3. **Windows Update:** حدّد "ساعات النشاط" الليلية كي لا يعيد التشغيل وسط الدوام. وجهّز UPS.

## 2) التثبيت
فك الضغط ثم في PowerShell كمسؤول:
```
cd apw-server\windows
powershell -ExecutionPolicy Bypass -File .\install.ps1
```
يثبّت الكود في `C:\apw`، وينشئ القاعدة والمفاتيح، ويسجّل مهمتين مجدولتين:
`APW-Server` (يعمل عند الإقلاع ويعيد المحاولة كل دقيقة عند الفشل) و`APW-Backup` (يومياً 02:00).
الخادم يستمع على `127.0.0.1` فقط، والقاعدة على `localhost` فقط، فلا شيء مكشوف على الشبكة.

## 3) بعد التثبيت
- الأدمن: `cd C:\apw\app` ثم `.\venv\Scripts\python.exe -m app.cli create-admin admin "الاسم"`
- النفق: `cloudflared service install <TOKEN>` والوجهة `http://localhost:8000`
- **انسخ `C:\apw\app\.env` و`C:\apw\secrets\backup-pass.txt` إلى فلاشة وخبّئها.**
- **وجّه النسخ الاحتياطي إلى قرص خارجي** (الافتراضي D: إن وُجد): `Get-ScheduledTask APW-Backup`.

## 4) قائمة فحص أول تشغيل
- [ ] `Invoke-RestMethod http://127.0.0.1:8000/health` يُرجع `ok`
- [ ] من هاتف خارج شبكة المجلس: `https://<نطاق النفق>/health` يعمل
- [ ] دخول الأدمن ينجح، ويُنشأ نائب ورمز دعوة
- [ ] أعد تشغيل الحاسوب دون تسجيل دخول: الخادم يعود وحده خلال دقيقتين
- [ ] شغّل `C:\apw\backup.ps1 -Dest D:\apw-backup` يدوياً وتأكد من ظهور ملفين `.7z`
- [ ] **جرّب الاستعادة** على جهاز آخر قبل الاعتماد عليه

## 5) التحديث والاستعادة
- **تحديث الكود:** استبدل مجلد المشروع وأعد تشغيل `install.ps1` (لا يمس `.env` ولا البيانات).
- **استعادة:** فك `db-*.7z` بـ 7-Zip بعبارة المرور، ثم `psql -U apw -h localhost -d apw -f db-....sql`. وفك `files-*.7z` إلى `C:\apw\data\files`. المفاتيح في `.env` يجب أن تكون نفسها.
- **السجلات:** `C:\apw\logs\api.log`

## ملاحظة
هذه السكربتات لم تُجرَّب على جهاز Windows فعلي بعد. شغّل قائمة الفحص أعلاه كاملة، وأرسل لي أي خطأ يظهر في `install.ps1` لأصلحه.
